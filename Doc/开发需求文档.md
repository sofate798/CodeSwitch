AI 供应商协议：供应商配置支持两种主流接入方式：

base_url — OpenAI 兼容协议（/v1/chat/completions）

base_url — Anthropic 协议（/v1/messages）

用户在创建供应商时必须显式选择协议类型，CodeSwitch 根据协议生成对应格式的 IDE 配置。

1. 项目概述
1.1 背景
当前 AI IDE（Cursor、Windsurf、Trae、Zed、GitHub Copilot 等）大量涌现，但每个 IDE 的自定义 AI 供应商配置方式各异、位置分散。开发者切换供应商或恢复官方默认配置时操作繁琐，容易遗忘备份。

1.2 目标
开发一款基于 Electron 的桌面工具 CodeSwitch，实现：

统一管理多个 AI IDE 的供应商配置

支持 OpenAI 协议 与 Anthropic 协议 两类供应商

一键应用自定义 AI 供应商

一键恢复 IDE 官方默认设置

配置快照与备份管理

1.3 核心价值
"一个按钮，切换你的 AI 大脑"

2. 目标用户
用户类型	场景
AI 重度开发者	同时使用多个 AI IDE，频繁切换供应商
企业开发者	需要在公司 API 和官方 API 之间切换
折腾党/极客	测试不同模型在不同 IDE 中的表现
初学者	想尝试自定义 API 但不懂配置文件

4. 非功能需求
4.1 性能
冷启动时间 ≤ 2s

IDE 扫描完成 ≤ 3s

配置应用响应 ≤ 500ms

连接测试超时 ≤ 5s

安装包体积 ≤ 100MB

4.2 安全
API Key 使用 AES-256-GCM 加密，密钥绑定设备

所有数据本地存储，不上传任何服务器

备份文件存放在用户数据目录，权限受限

敏感信息在 UI 中默认脱敏显示（sk-****xxxx）

连接测试直接在本机发起，不经中转服务器

4.3 可靠性
所有文件写入操作采用 写临时文件 + 原子替换 策略

失败自动回滚

崩溃恢复：启动时检测未完成事务

4.4 兼容性
Windows 10/11 x64

后续支持 macOS 12+ / Ubuntu 20.04+

4.5 可用性
界面简洁，主要操作 3 步内完成

全中文 + 英文双语支持

首次启动引导流程

4.6 UI 规范（强制）
禁止使用任何 Emoji 字符（含界面、菜单、托盘、通知、文档截图）

5.3 核心模块设计
5.3.1 IDE Adapter（适配器模式）
typescript
interface IDEAdapter {
  id: string;                    // 唯一标识
  name: string;                  // 显示名
  supportedProtocols: Protocol[];// 支持的协议类型
  detect(): Promise<boolean>;    // 是否安装
  getConfigPath(): string;       // 配置文件路径
  readConfig(): Promise<Config>; // 读取
  writeConfig(cfg: Config): Promise<void>; // 写入
  resetConfig(): Promise<void>;  // 恢复默认
  getDefaultTemplate(): Config;  // 默认模板
}

type Protocol = 'openai' | 'anthropic';
5.3.2 Provider Service（协议适配）
typescript
interface Provider {
  id: string;
  name: string;
  protocol: 'openai' | 'anthropic';
  apiKey: string;      // 加密存储
  baseUrl: string;
  model: string;
  group?: string;
}

interface ProviderService {
  test(provider: Provider): Promise<TestResult>;
  toIDEConfig(provider: Provider, ide: IDEAdapter): Config;
}
协议转换示例（写入 IDE 配置时）：

OpenAI 协议写入格式：

json
{
  "apiKey": "sk-xxx",
  "baseUrl": "https://api.openai.com/v1",
  "model": "gpt-4o"
}
Anthropic 协议写入格式：

json
{
  "apiKey": "sk-ant-xxx",
  "baseUrl": "https://api.anthropic.com",
  "model": "claude-3-5-sonnet-20241022",
  "protocol": "anthropic"
}
5.3.3 备份策略
备份目录：%APPDATA%/CodeSwitch/backups/{ideId}/{timestamp}.bak

保留策略：每个 IDE 保留最近 10 个备份

元数据文件：meta.json 记录备份时间、来源

5.3.4 加密方案
密钥派生：PBKDF2(设备指纹 + 固定盐)

加密算法：AES-256-GCM

存储位置：%APPDATA%/CodeSwitch/secure/vault.enc

10. 风险与对策
风险	等级	对策
IDE 配置文件路径/格式变更	高	适配器模式 + 用户手动指定路径 + 远程配置热更新
加密 Key 泄露	高	设备绑定 + 本地存储 + 不上传
用户误操作恢复	中	二次确认 + 自动备份 + 回滚机制
权限不足无法写入	中	提示管理员运行 + UAC 支持
多 IDE 同时修改冲突	低	串行化操作 + 文件锁
Electron 包体积大	低	使用 asar + 精简依赖
协议不兼容	中	应用前校验 IDE 支持协议，不兼容时给出明确提示
品牌 Logo 侵权	中	使用简化几何图标或获授权资源
11. 验收标准 (MVP)
□ 能自动识别至少 5 个主流 AI IDE
□ 能添加/编辑/删除供应商，必须选择 OpenAI 或 Anthropic 协议
