# CodeSwitch 项目开发文档 (PRD)

> 版本：v1.1.0 (MVP)
> 日期：2026-10-09
> 技术栈：Electron + Vue 3 + TypeScript + Vite
> 目标平台：Windows 10/11 (优先)，后续扩展 macOS/Linux
> 图标规范：全项目禁止使用任何 Emoji 图标，统一使用矢量图标组件库

## 1. 项目概述

### 1.1 背景

当前 AI IDE（Cursor、Windsurf、Trae、Zed、GitHub Copilot 等）大量涌现，但每个 IDE 的自定义 AI 供应商配置方式各异、位置分散。开发者切换供应商或恢复官方默认配置时操作繁琐，容易遗忘备份。

### 1.2 目标

开发一款基于 Electron 的桌面工具 CodeSwitch，实现：

- 统一管理多个 AI IDE 的供应商配置
- 支持 OpenAI 协议 与 Anthropic 协议 两类供应商
- 一键应用自定义 AI 供应商
- 一键恢复 IDE 官方默认设置
- 配置快照与备份管理

### 1.3 核心价值

> "一个按钮，切换你的 AI 大脑"

## 2. 目标用户

| 用户类型 | 场景 |
| --- | --- |
| AI 重度开发者 | 同时使用多个 AI IDE，频繁切换供应商 |
| 企业开发者 | 需要在公司 API 和官方 API 之间切换 |
| 折腾党/极客 | 测试不同模型在不同 IDE 中的表现 |
| 初学者 | 想尝试自定义 API 但不懂配置文件 |

##### FR-02-2 协议类型详细规范

**协议 A：OpenAI 兼容协议**

- 请求路径：`{base_url}/v1/chat/completions`
- 请求头：

  ```text
  Authorization: Bearer {api_key}
  Content-Type: application/json
  ```

- 请求体示例：

  ```json
  {
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "hello"}],
    "stream": true
  }
  ```

- 典型 Base URL：
  - https://api.openai.com
  - https://api.deepseek.com
  - https://openrouter.ai/api
  - https://dashscope.aliyuncs.com/compatible-mode

**协议 B：Anthropic 协议**

- 请求路径：`{base_url}/v1/messages`
- 请求头：

  ```text
  x-api-key: {api_key}
  anthropic-version: 2023-06-01
  Content-Type: application/json
  ```

- 请求体示例：

  ```json
  {
    "model": "claude-3-5-sonnet-20241022",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "hello"}]
  }
  ```

- 典型 Base URL：
  - https://api.anthropic.com
  - https://api.anthropic.com/v1（部分代理）

##### FR-02-7 连接测试逻辑

- OpenAI 协议：调用 `{base_url}/v1/models` 或最小 Chat Completion 请求
- Anthropic 协议：调用 `{base_url}/v1/messages` 发送最小消息
- 返回 2xx 视为成功，超时 5s
- 结果：按消息码归类（成功 / 鉴权失败 / HTTP 状态码 / 超时 / 网络错误 / 地址非法 / 密钥不可用），不回显上游响应体

## 4. 非功能需求

### 4.1 性能

- 冷启动时间 ≤ 2s
- IDE 扫描完成 ≤ 3s
- 配置应用响应 ≤ 500ms
- 连接测试超时 ≤ 5s
- 安装包体积 ≤ 100MB

### 4.2 安全

- API Key 使用 AES-256-GCM 加密，主密钥经 Electron safeStorage（Windows=DPAPI）在本机保护，绑定设备
- 所有数据本地存储，不上传任何服务器
- 备份文件存放在用户数据目录，权限受限
- 敏感信息在 UI 中默认脱敏显示（`sk-****xxxx`），尾号取自后端密文解析，前端不接触明文
- 连接测试直接在本机发起，不经中转服务器
- 本地转发网关仅监听 127.0.0.1，需随机 token 才能访问 API（`/health` 除外），校验 Host/Origin 防 DNS rebinding 与跨域，请求体上限 32 MB
- 「打开目录/在文件夹中显示」类操作受数据目录 + IDE 配置路径白名单约束，防止渲染进程任意开启本机路径
- 入参在主进程侧收口校验（字段长度 / 枚举白名单 / URL 合法性 / 重名拦截）；编辑供应商时密钥掩码占位不触发重加密，避免把占位符当真实 Key 写入

### 4.3 可靠性

- 所有文件写入操作采用 写临时文件 + 原子替换 策略
- 失败自动回滚
- 崩溃恢复：启动时检测未完成事务

### 4.4 兼容性

- Windows 10/11 x64
- 后续支持 macOS 12+ / Ubuntu 20.04+

### 4.5 可用性

- 界面简洁，主要操作 3 步内完成
- 全中文 + 英文双语支持
- 首次启动引导流程

### 4.6 UI 规范（强制）

- 禁止使用任何 Emoji 字符（含界面、菜单、托盘、通知、文档截图）
- 所有图标必须来自统一图标组件库（见 §7.2）
- 图标尺寸、颜色、描边风格必须统一

### 5.2 进程架构

CodeSwitch 由 electron-vite 拆分为 main / preload / renderer 三个构建目标，渲染进程通过 contextBridge 暴露的 `window.api` 与主进程 IPC 通信（实际接口见 `electron/shared/types.ts` 的 API 接口；README 与代码为准）：

```text
┌─────────────────────────────────────────┐
│            Renderer Process             │
│  Vue 3 UI (IDE 列表 / 供应商 / 快照)      │
└──────────────┬──────────────────────────┘
               │ IPC (contextBridge)
┌──────────────▼──────────────────────────┐
│              Main Process               │
│  ├── IDE Scanner Service                │
│  ├── Config Adapter (Registry)          │
│  ├── Provider Service (OpenAI/Anthropic)│
│  ├── Local Forwarding Gateway           │
│  ├── Backup Service                     │
│  ├── Crypto Service (AES-256-GCM)       │
│  ├── Snapshot Service                   │
│  └── Logger Service                     │
└──────────────┬──────────────────────────┘
               │ fs / http
┌──────────────▼──────────────────────────┐
│     File System / IDE Configs / API     │
└─────────────────────────────────────────┘
```

IDE 探测与写入按适配器的 storage 策略分派到四个存储后端（sqliteStore / tomlStore / envStore 与 JSON 原子写），写入前由 processGuard 检测目标 IDE 是否运行；本地转发网关（proxy + proxyTranslate）提供跨协议转换与流式转发。IPC 通道统一采用 `<域>:<动作>` 命名（如 `ide:scan`、`provider:save`、`proxy:status`），并包装为结构化 OpResult 返回。

### 5.3 核心模块设计

#### 5.3.1 IDE 适配器注册表（数据驱动）

新增或调整一款 IDE 支持，只需在 `electron/adapters/registry.ts` 的 `IDE_REGISTRY` 数组追加一条 `IDEAdapterDef`，无需改动扫描或写入逻辑。路径模板中的 `${ENV}` 占位符由 `resolvePath` 在运行时展开；任一环境变量缺失则整条路径判为无效并被过滤。

检测优先级：homeMarkers（家目录标记，跨盘符最可靠）> detectPaths（exe 安装位置）> configPaths。

```typescript
interface IDEAdapterDef {
  id: string; name: string; icon: string;
  protocols: Protocol[];              // 'openai' | 'anthropic'
  configPaths: string[];              // 候选配置文件绝对路径（可含 ${ENV}）
  detectPaths: string[];              // exe / 安装目录探测
  homeMarkers?: string[];             // 家目录标记（优先级最高）
  storage: StorageSpec;               // 落盘策略，见 5.3.2
  processNames?: string[];            // 写入前检测是否在运行
  capability?: 'auto' | 'assist' | 'manual'; // 缺省则按 storage 推断
  writable?: boolean;                 // false=纯手动，UI 禁用应用按钮
  noteKey?: string;                   // 用户提示的 i18n key（杜绝硬编码中文）
}
```

#### 5.3.2 存储策略 StorageSpec（四选一，决定供应商三要素如何落盘）

- **json**：明文 JSON，按点路径（fields.apiKey/baseUrl/model）写入，文件不存在时可自动创建（Zed / Antigravity）。
- **sqlite**：VS Code 系 state.vscdb 的 ItemTable，用 sql.js 整库读写；已知 rowKey 直接定位，未知 schema 用 probeContains 自适应探测凭证行，encryptSecret=true 时镜像 DPAPI 加密（Cursor / Windsurf / Trae / Kiro / CodeBuddy / Qoder）。
- **toml**：config.toml 顶层标量 + 表段（scalars / table / tableValues），密钥另落到 secretFile 指定的 JSON（Codex）。
- **env**：.env 以 KEY=VALUE 写入（Gemini CLI）。

> 说明：凭证槽位无法自动定位的 sqlite 型 IDE 会回退为 assist 能力（生成配置 + 一键复制）；GitHub Copilot 因密钥存于系统级密钥库，固定为 assist。

#### 5.3.3 Provider 服务（协议测试 + 三要素落点）

- `testProvider()`：按协议发最小请求，OpenAI 优先 GET /v1/models、失败降级 /v1/chat/completions，Anthropic POST /v1/messages；两段共享 5s 总超时（AbortController）；返回结构化 OpResult（testOk / testAuthFailed / testHttpErr / testTimeout / testNetErr / testBadUrl / keyUnavailable），不回显上游响应体。
- baseUrl 归一拆为两条路径：连接测试用 `resolveTestBaseUrl`，落盘用 `normalizeWriteBaseUrl`（按 per-IDE 的 BASE_URL_WRITE_MODE 决定补/去 /v1，杜绝 /v1/v1）。
- `providerValues()` / `applyFieldsToConfig()`：把 apiKey / baseUrl / model 按存储策略映射到目标载体。

```typescript
interface Provider {
  id: string; name: string; protocol: Protocol;
  apiKey: string;   // 加密存储，格式 enc2:<iv>:<tag>:<data>
  keyTail?: string; // 明文后 4 位，供 sk-****xxxx 脱敏展示
  baseUrl: string; model: string; group?: string;
  createdAt: number; updatedAt: number;
}
```

#### 5.3.4 凭证加密方案（两套，互不混用）

- **自有存储（CodeSwitch 内）**：AES-256-GCM。首次运行生成随机 256-bit 主密钥，用 Electron safeStorage（Windows=DPAPI）加密后存到 `<userData>/secure/master.key`；密文版本化为 `enc2:<iv>:<tag>:<data>`，decrypt 兼容旧 `enc:`（设备指纹 scrypt 派生，仅用于历史数据）并在保存时惰性升级为 `enc2:`，零数据丢失；safeStorage 不可用时降级为受文件权限保护的本地主密钥。主密钥不可用抛 `KeyUnavailableError`，绝不静默明文回退。
- **目标 IDE 凭证（secureValue.ts）**：镜像其原生格式——读时若原值是 DPAPI base64 密文则用 safeStorage 解密还原；写时原值密文则用 safeStorage 重加密，原值明文则写明文，绝不写入目标 IDE 无法解析的格式。

#### 5.3.5 应用 / 恢复流程（ideScanner.ts）

对外提供 scanIDEs / applyProvider / resetIDE / manualAdd / generateConfig / checkIdeRunning。应用供应商时：

1. processGuard.isIdeRunning 检测目标（sqlite / toml 类）是否在运行，运行中拒绝写入并提示先关闭；
2. 按 storage.kind 分派到 sqliteStore / tomlStore / envStore 与 JSON 原子写；
3. 写入前由 backup.backupFile 备份原配置（写临时文件 + 原子替换，失败回滚）；
4. 全程以 OpResult（code + args）返回，前端按 i18n 渲染。

#### 5.3.6 本地转发网关（proxy.ts + proxyTranslate.ts）

在 127.0.0.1 起 HTTP 服务，入站 /v1/chat/completions（OpenAI）与 /v1/messages（Anthropic），按目标供应商协议自动双向转换（含流式 SSE）；同协议直接透传。安全：启动生成随机 token（Bearer / x-codeswitch-token / ?token=），校验 Host 防 DNS rebinding，CORS 收紧为本机 Origin；请求体超上限（32 MB）拒收并回 413；客户端断开经 AbortController 中止进行中的上游请求；网关 token 在前端脱敏展示，需显式点击才查看/复制。转换纯函数独立于 Electron 便于单测；跨协议工具调用仅非流式完整映射为其已知限制。

#### 5.3.7 持久化 / 备份 / 数据目录 / 日志

- **store.ts**：electron-store JSON 持久化；多键读改写走 mutate 串行队列，消除并发竞态。
- **backup.ts**：备份目录 `<userData>/backups/{ideId}/{timestamp}-{rand}.bak`（+ .extra-N.bak 携带 -wal/-shm 附属文件）与 meta.json 清单；每个 IDE 仅保留最近 10 个（MAX_PER_IDE）。
- **snapshot.ts**：保存 / 切换全部 IDE 的供应商绑定快照。
- **paths.ts + main/bootstrap.ts**：自定义数据目录在 electron-store 实例化前重定向 userData（引导文件存于 Roaming/appData，位置恒定），迁移时搬运 config.json / backups / logs。
- **logger.ts**：内存缓冲 + 按日文件落盘；仅记录非敏感信息，绝不写入明文密钥。

#### 7.2.2 强制规则

- 禁止任何 Emoji：不得在 UI、菜单、托盘、通知、日志、文档、README、GitHub Issues 模板中出现 Emoji 字符（表情类 Unicode 符号，含各类图形/面孔/手势图标）。

## 10. 风险与对策

| 风险 | 等级 | 对策 |
| --- | --- | --- |
| IDE 配置文件路径/格式变更 | 高 | 适配器模式 + 用户手动指定路径 + 远程配置热更新 |
| 加密 Key 泄露 | 高 | 设备绑定 + 本地存储 + 不上传 |
| 用户误操作恢复 | 中 | 二次确认 + 自动备份 + 回滚机制 |
| 权限不足无法写入 | 中 | 提示管理员运行 + UAC 支持 |
| 多 IDE 同时修改冲突 | 低 | 串行化操作 + 文件锁 |
| Electron 包体积大 | 低 | 使用 asar + 精简依赖 |
| 协议不兼容 | 中 | 应用前校验 IDE 支持协议，不兼容时给出明确提示 |
| 品牌 Logo 侵权 | 中 | 使用简化几何图标或获授权资源 |
